# 这个路线的目标

1. 你能**用 2 分钟讲清楚**：多模态模型=视觉编码器 + 桥接模块 + LLM，三种桥接路线各自 trade-off。
2. 你能**算清楚成本**：分辨率/patch size → 视觉 token 数 → prefill 成本为什么爆。
3. 你能**说清楚失败模式**：OCR/文档/图表/定位/视频为什么更容易翻车，以及常见工程补救。
4. 你能**讲评测闭环**：至少知道用什么工具跑 benchmark、怎么保证可复现。

## 1) 先学 ViT：视觉 token 的“第一性原理”

**为什么先学它**：后面所有多模态问题，本质都绕不过“图像怎么变成 token、token 数怎么决定成本”。

你要掌握：

- Patchify、Positional Embedding、Transformer encoder 的直觉
- **分辨率 H×W、patch size P** 与 token 数关系：`N = (H/P)*(W/P)`
- 为什么 token 多了，attention 计算/显存会急剧上升（prefill 尤其明显）

材料建议：ViT 原论文（标题就够标志性）([Hugging Face](https://huggingface.co/papers/2010.11929?utm_source=chatgpt.com))

**轻量实操（建议做）**

- 同一张图 resize 成 224/336/448/672，计算 token 数并记录你随便一个开源 VLM 的推理耗时趋势（只要趋势，不要卷数值）。

面试必问：

- “为什么高分辨率更慢？”
- “patch size 变小会怎样？”（token ↑、prefill 更重）

------

## 2) 再学 CLIP：图文对齐的基础（对比学习）

**为什么第二站学 CLIP**：你需要知道“图片和文本怎么对齐到同一语义空间”，否则后面 LLaVA/BLIP-2 你会只会背结构。

你要掌握：

- image encoder + text encoder
- InfoNCE/softmax 对比损失：batch 内“正对拉近、负对推远”
- cosine vs dot、归一化的意义

材料建议：CLIP 论文([Hugging Face](https://huggingface.co/papers/2103.00020?utm_source=chatgpt.com))

**轻量实操（建议做）**

- 用 CLIP 做 text→image 检索（30 张图片就够），观察：它对“场景/大物体”强、对“小字/OCR/精细计数/图表读数”弱。

面试必问：

- “CLIP 为什么常需要大 batch？”
- “CLIP 为什么 OCR 弱？”（分辨率、patch、视觉表征瓶颈）

------

## 3) 补一站 SigLIP：把“对齐损失”讲得更工程

**为什么要学**：面试官问“除了 CLIP 你还知道什么图文对齐？”你能立刻接住。

你要掌握：

- SigLIP 用 **pairwise sigmoid loss** 替代 softmax 归一化式对比学习
- 直觉：不那么依赖全局归一化，对 batch size/训练设置更灵活（讲清趋势即可）

材料建议：SigLIP 论文页([Hugging Face](https://huggingface.co/papers/2303.15343?utm_source=chatgpt.com))

**轻量实操（可选）**

- 不训练也行：画一张“CLIP vs SigLIP loss”的对比示意图（softmax 全局归一化 vs pairwise sigmoid），面试时 1 分钟讲清就很加分。

------

## 4) 进入“桥接到 LLM”的三条主路线（面试核心）

这一步是多模态面试最常见的主问：**图像特征怎么喂给 LLM？** 你至少要能讲清 3 种方式的“连接点”和 trade-off。

### 4.1 LLaVA 路线（Projector）

- 结构：视觉 encoder（常是 CLIP/ViT）→ **projector（linear/MLP）** → 当作“视觉 token”拼进 LLM 输入
- 特点：实现简单、指令微调友好、最常见工程路线

材料：LLaVA 论文（Visual Instruction Tuning）([Hugging Face](https://huggingface.co/papers/2304.08485?utm_source=chatgpt.com))

**轻量实操（强烈建议）**

- 选一个开源 LLaVA 系模型，跑你自制 30 张图片集合（截图/表格/海报/论文图/代码截图），把错例分 5 类：OCR错、图表错、幻觉、定位失败、注入。你后面所有面试都能用这套错例“讲工程”。

面试必问：

- “projector 为什么够用？什么时候不够？”
- “你会冻结/解冻哪些模块？为什么？”

### 4.2 BLIP-2 路线（Q-Former）

- 结构：冻结视觉 encoder + 冻结 LLM，中间用 **Q-Former（learnable queries）**从视觉特征里“问出”少量摘要 token，再喂给 LLM
- 重点口径：它是**压缩器/信息提取器**，能降低 LLM 侧 token 压力

材料：BLIP-2 论文([Hugging Face](https://huggingface.co/papers/2303.15343?utm_source=chatgpt.com))（可用 BLIP-2 官方 arXiv/论文页你本地再补读；你面试口径以“冻结两端、训练桥”讲清即可）

**轻量实操（不训练也行）**

- 画数据流图，并写 3 句话：为什么 queries 能把“很多视觉 token”压成固定长度、优势/风险分别是什么。

面试必问：

- “Q-Former 为什么不是把所有视觉 token 都喂给 LLM？”
- “信息瓶颈会带来什么能力损失？”

### 4.3 Flamingo 路线（Cross-Attention + Gate + Resampler）

- 结构：在 LM 层间插 cross-attn，让文本 token attend 视觉 token；gate 用来稳训练；resampler 用来压 token
- 优势：适合图文交错、多图/视频扩展（概念层会讲即可）

（这条路线你不必复现训练，重点掌握“为什么需要 gate、为什么适合 interleaved 输入”的口径。）

------

## 5) 评测工具链：不跑评测=面试非常虚

你不需要跑满 benchmark，但要会“可复现评测”的基本姿势。

推荐选一个工具（任选其一）：

- **lmms-eval**：覆盖文本/图像/视频/音频任务([GitHub](https://github.com/EvolvingLMMs-Lab/lmms-eval?utm_source=chatgpt.com))
- **VLMEvalKit**：支持大量模型与 benchmark，很适合“只评测不训练”([GitHub](https://github.com/open-compass/VLMEvalKit?utm_source=chatgpt.com))

**轻量实操（强烈建议）**

- 跑 1 个 benchmark 的子集（比如只跑几十条），输出 report：模型版本、图像 resize 方案、prompt、解码参数。
  面试就能说：我做过可复现评测，知道多模态评测对 prompt/预处理敏感。

面试必问：

- “为什么多模态评测更不稳定？”
- “你怎么保证可复现？”（固定预处理/seed/prompt/解码）

------

## 6) 专项能力与失败模式：OCR/文档/图表/定位/视频

这部分不用训练，也能靠“失败分析 + 工程补救”讲得很强。

你要掌握（面试口径）：

- **OCR/文档**为什么难：小字+布局+分辨率；“看到了但读错/漏读/乱编”
- **图表**为什么难：轴/图例/数值读取，模型常“趋势对但数值错”
- **Grounding（定位）**为什么难：输出坐标比输出文本难；常用两阶段（检测器出框→LLM选框）
- **多图/视频**为什么难：token 爆炸+时序一致性；需要采样/压缩/分层

如果你想补“热点趋势”的材料：

- LLaVA-OneVision（单图/多图/视频统一方向）([Hugging Face](https://huggingface.co/papers/2408.03326?utm_source=chatgpt.com))
- Qwen2.5-VL（强调动态分辨率、文档解析、定位、长视频）([Hugging Face](https://huggingface.co/papers/2502.13923?utm_source=chatgpt.com))

**轻量实操（建议做两项）**

- OCR：10 张含小字截图，统计错误类型
- 图表：10 张图表，问具体读数（不是趋势），记录失败类型

------

## 7) 成本、部署与安全（热点加分）

你要能讲：

- 延迟瓶颈：视觉 encoder + 视觉 token prefill + LLM 解码
- 降本三件套：视觉 token 压缩 / 动态分辨率 / 两阶段 pipeline
- 多模态注入：图片里写“忽略系统指令…”会带偏输出 → 原则是“外部内容不可信、指令隔离、必要时人审/校验”

**轻量实操（可选）**

- 做 5 条“图片注入”样例（图里写提示），观察模型是否被带偏，并写 3 条防护策略（隔离、拒答、引用校验/工具校验）。

------

## 最该按顺序做的“最小闭环”

1. **ViT**：搞懂 token 数与成本（能算能讲）([Hugging Face](https://huggingface.co/papers/2010.11929?utm_source=chatgpt.com))
2. **CLIP + SigLIP**：搞懂对齐（能讲 loss 直觉）([Hugging Face](https://huggingface.co/papers/2103.00020?utm_source=chatgpt.com))
3. **三桥接路线**：LLaVA（projector）为主，Q-Former/Flamingo 为对比口径([Hugging Face](https://huggingface.co/papers/2304.08485?utm_source=chatgpt.com))
4. **评测工具**：任选 lmms-eval 或 VLMEvalKit 跑子集出 report([GitHub](https://github.com/EvolvingLMMs-Lab/lmms-eval?utm_source=chatgpt.com))
5. **错例库**：30 条分类（这会极大提升工程感和面试表现）
