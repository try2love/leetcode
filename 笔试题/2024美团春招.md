## 1. 小美的平衡矩阵

### 题目描述

小美拿到了一个 $n \times n$ 的矩阵，其中每个元素是 $0$ 或者 $1$。

小美认为一个矩形区域是**完美**的，当且仅当该区域内 $0$ 的数量恰好等于 $1$ 的数量。

现在，小美希望你回答有多少个 $i \times i$ 的完美矩形区域。你需要回答 $1 \le i \le n$ 的所有答案。

### 输入描述

第一行输入一个正整数 $n$，代表矩阵大小。

接下来的 $n$ 行，每行输入一个长度为 $n$ 的 $01$ 串，用来表示矩阵。

限制条件：$1 \le n \le 200$

### 输出描述

输出 $n$ 行，第 $i$ 行输出 $i \times i$ 的完美矩形区域的数量。

------

### 示例 1

**输入：**

Plaintext

```
4
1010
0101
1100
0011
```

**输出：**

Plaintext

```
0
7
0
1
```

------

### 复杂度及空间限制

- **时间限制：** C/C++ 1秒，其他语言 2秒
- **空间限制：** C/C++ 256M，其他语言 512M

------

**解题小贴士：**

这道题的 $n$ 最大为 200，意味着 $O(n^3)$ 的暴力枚举配合**二维前缀和**优化是可以轻松通过的。

1. 将矩阵中的 $0$ 视为 $-1$，$1$ 视为 $1$。

3. 只有当 $i$ 为**偶数**时，才可能存在完美矩形（因为奇数个格子的总和永远不可能是 0）。

### 参考答案

这是一个经典的**二维前缀和**问题。由于题目要求统计 $i \times i$ 正方形区域内 0 和 1 的数量是否相等，我们可以将矩阵中的 **0 全部替换为 -1**。

这样一来，“0 的数量等于 1 的数量”就等价于“**正方形区域内所有元素的总和等于 0**”。

### 解题思路

1. **预处理矩阵**：将所有 `0` 变为 `-1`。

2. **二维前缀和**：构建前缀和矩阵 `S`，其中 $S[i][j]$ 表示从 $(1,1)$ 到 $(i,j)$ 的矩形总和。计算公式为：

   $$S[i][j] = matrix[i][j] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]$$

3. **计算子矩阵和**：对于任意一个边长为 $k$ 的正方形，其右下角坐标为 $(i,j)$，左上角坐标为 $(i-k+1, j-k+1)$，其总和计算公式为：

   $$\text{Sum} = S[i][j] - S[i-k][j] - S[i][j-k] + S[i-k][j-k]$$

4. **遍历与计数**：对于每个可能的边长 $k$（必须是偶数，因为奇数长度的正方形格子总数是奇数，不可能 0 和 1 相等），遍历所有可能的右下角坐标 $(i, j)$。

------

### Python ACM 模式代码实现

```python
import sys

def solve():
    # 读取 n
    line = sys.stdin.readline()
    if not line:
        return
    n = int(line.strip())
    
    # 读取矩阵并转化为 -1 和 1
    matrix = []
    for _ in range(n):
        row = list(map(int, list(sys.stdin.readline().strip())))
        # 0 变 -1, 1 不变
        matrix.append([1 if x == 1 else -1 for x in row])
    
    # 构建二维前缀和矩阵 (n+1) x (n+1)
    s = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, n + 1):
            s[i][j] = matrix[i-1][j-1] + s[i-1][j] + s[i][j-1] - s[i-1][j-1]
            
    # 依次计算边长 i 从 1 到 n 的结果
    for k in range(1, n + 1):
        # 奇数边长的正方形格子总数是奇数，和不可能为 0
        if k % 2 != 0:
            print(0)
            continue
            
        count = 0
        # 遍历所有可能的右下角坐标 (i, j)，这里的ij考虑的就是以ij为右下角元素的变长为k的正方形的和
        for i in range(k, n + 1):
            for j in range(k, n + 1):
                # 计算边长为 k 的子矩阵和
                sub_sum = s[i][j] - s[i-k][j] - s[i][j-k] + s[i-k][j-k]
                if sub_sum == 0:
                    count += 1
        print(count)

if __name__ == "__main__":
    solve()
```

------

### 复杂度分析

- **时间复杂度**：$O(n^3)$。构建前缀和需要 $O(n^2)$，后续对于每个边长 $k$ 遍历矩阵需要 $O(n^2)$，总共 $n$ 个边长，所以是 $O(n \cdot n^2) = O(n^3)$。对于力扣或一般竞赛中 $n \le 300$ 的数据量，这个复杂度是可以接受的。
- **空间复杂度**：$O(n^2)$，用于存储前缀和矩阵。

### 逻辑提示

在处理这种“计数相等”的问题时，**转化为求和为 0** 是一种非常通用的技巧，不仅适用于二维矩阵，也适用于一维数组（如：求 0 和 1 数量相等的连续子数组）。

## 2. 小美的数组询问

### 题目描述

小美拿到了一个由正整数组成的数组，但其中有一些元素是未知的（用 $0$ 来表示）。

现在小美想知道，如果那些未知的元素在区间 $[l, r]$ 范围内随机取值的话，数组所有元素之和的最小值和最大值分别是多少？

共有 $q$ 次询问。

### 输入描述

第一行输入两个正整数 $n, q$，代表数组大小和询问次数。

第二行输入 $n$ 个整数 $a_i$，其中如果输入的 $a_i$ 为 $0$，那么说明 $a_i$ 是未知的。

接下来的 $q$ 行，每行输入两个正整数 $l, r$，代表一次询问。

**数据范围：**

- $1 \le n, q \le 10^5$
- $0 \le a_i \le 10^9$
- $1 \le l \le r \le 10^9$

### 输出描述

输出 $q$ 行，每行输出两个正整数，代表所有元素之和的最小值和最大值。

------

### 示例 1

**输入：**

Plaintext

```
3 2
1 0 3
1 2
4 4
```

**输出：**

Plaintext

```
5 6
8 8
```

**例子说明：**

只有第二个元素是未知的。

- 第一次询问，数组最小的和是 $1+1+3=5$，最大的和是 $1+2+3=6$。
- 第二次询问，显然数组的元素和必然为 $8$。

------

### 具体的代码实现 (Python)

由于题目涉及多次询问且数据规模达到 $10^5$，我们需要先预处理数组中已知元素的总和以及 $0$ 的个数，从而在 $O(1)$ 的时间内回答每次询问。

```python
import sys

def solve():
    # 使用 fast I/O
    input = sys.stdin.read().split()
    if not input:
        return
    
    ptr = 0
    n = int(input[ptr])
    q = int(input[ptr+1])
    ptr += 2
    
    # 预处理：计算已知元素的和，以及统计 0 的个数
    current_sum = 0
    zero_count = 0
    
    for _ in range(n):
        val = int(input[ptr])
        if val == 0:
            zero_count += 1
        else:
            current_sum += val
        ptr += 1
        
    results = []
    # 处理 q 次询问
    for _ in range(q):
        l = int(input[ptr])
        r = int(input[ptr+1])
        ptr += 2
        
        # 最小和：所有 0 替换为 l
        min_sum = current_sum + zero_count * l
        # 最大和：所有 0 替换为 r
        max_sum = current_sum + zero_count * r
        
        results.append(f"{min_sum} {max_sum}")
    
    # 一次性输出提高效率
    sys.stdout.write("\n".join(results) + "\n")

if __name__ == "__main__":
    solve()
```

### 关键点解析

1. **预处理**：已知数字的和 `current_sum` 是固定的，变量只取决于 `zero_count` 个 $0$ 替换成什么。
2. **贪心策略**：要使总和最小，所有 $0$ 都应取区间左端点 $l$；要使总和最大，所有 $0$ 都应取区间右端点 $r$。
3. **效率优化**：使用 `sys.stdin.read().split()` 能够快速读取大量数据，这在 ACM 模式的 Python 环境中非常重要，可以避免因为输入输出导致超时（TLE）。

## 3. 小美的 MT

### 我的解答

```python
import sys
from collections import Counter
def solve(k, strs):
    cnt = Counter(strs)
    already = cnt["M"] + cnt["T"]
    return already + min(len(strs)-already, k)

data = sys.stdin.readlines()
tmp = list(map(int, data[0].strip().split()))
n, k = tmp[0], tmp[1]
strs = data[1][:n]
print(solve(k, strs),end="")
```

### 具体的代码实现 (Python)

这道题的逻辑非常简单：我们不需要关心修改哪个字符变成 'M' 还是 'T'，因为题目只要求 'M' 和 'T' 的**总数**最大。

1. 统计原始字符串中已经是 'M' 或 'T' 的字符数量 `count`。
2. 剩余的非 'M' 或 'T' 字符数量为 `n - count`。
3. 每次操作（最多 $k$ 次）都可以把一个非 'M'/'T' 字符变成 'M' 或 'T'。
4. 最终数量即为：`原始 MT 数量 + min(剩余字符数量, k)`。

```python
import sys

def solve():
    # 读取第一行 n 和 k
    line1 = sys.stdin.readline().split()
    if not line1:
        return
    n, k = map(int, line1)
    
    # 读取第二行字符串
    s = sys.stdin.readline().strip()
    
    # 1. 统计当前字符串中 'M' 和 'T' 的总数
    current_mt_count = 0
    for char in s:
        if char == 'M' or char == 'T':
            current_mt_count += 1
            
    # 2. 剩余的非 'M'/'T' 字符个数
    other_chars_count = n - current_mt_count
    
    # 3. 最多可以把 min(other_chars_count, k) 个其他字符变成 'M' 或 'T'
    ans = current_mt_count + min(other_chars_count, k)
    
    print(ans)

if __name__ == "__main__":
    solve()
```

### 关键点解析

- **贪心策略**：由于题目问的是“最多共有多少个”，我们显然应该优先把那些不是 'M' 或 'T' 的字符改掉。
- **边界情况**：如果 $k$ 大于非 'M'/'T' 字符的总数，我们也只能把所有字符都变成 'M' 或 'T'，所以最终结果不能超过字符串总长度 $n$。这在代码中通过 `min(other_chars_count, k)` 得到了处理。
- **时间复杂度**：$O(n)$，只需遍历一遍字符串。
- **空间复杂度**：$O(n)$，用于存储字符串。

## 4. 小美的朋友关系

**题目背景**

小美认为，在人际交往中，随着时间的流逝，朋友的关系也是会慢慢变淡的，最终朋友关系就淡忘了。

现在初始有一些朋友关系，存在一些事件会导致两个人淡忘了他们的朋友关系。小美想知道某一时刻中，某两人是否可以通过朋友介绍互相认识？

**事件共有 2 种：**

1. `1 u v`：代表编号 $u$ 的人和编号 $v$ 的人淡忘了他们的朋友关系。
2. `2 u v`：代表查询编号 $u$ 的人和编号 $v$ 的人是否能通过朋友介绍互相认识。

**注：** 介绍可以有多层。例如：2 号把 1 号介绍给 3 号，然后 3 号再把 1 号介绍给 4 号，这样 1 号和 4 号就认识了。

- 空间限制：C/C++ 256M，其他语言 512M
- $1 \le n \le 10^9$
- $1 \le m, q \le 10^5$
- $1 \le u, v \le n$
- $1 \le op \le 2$

------

你的代码尝试通过手动维护邻接表并用 `while` 循环不断 `union` 集合来寻找连通性。这种思路主要存在以下几个问题：

1. **时间复杂度过高 (致命伤)**：
   - 在查询（`method == 2`）时，你使用了一个 `while pre != cur` 循环来做类似广度优先搜索（BFS）的操作。在最坏情况下，为了确认连通性，你可能需要遍历图中的所有节点。
   - 对于 $10^5$ 次询问，每次询问都进行 $O(N)$ 或 $O(M)$ 的搜索，总复杂度接近 $O(Q \times M)$，这会导致 **TLE (超时)**。
2. **空间复杂度问题**：
   - `barrel = [None] * (n + 1)`：题目给出的 $n$ 高达 $10^9$。虽然你的 `m` 和 `q` 只有 $10^5$，但直接开辟 $10^9$ 大小的列表会导致 **MLE (内存溢出)**。
3. **集合操作的误用**：
   - `tmp2.union(barrel[x].connect)`：Python 中 `set.union()` 会返回一个新集合，它**不会改变原集合 `tmp2`**。你应该使用 `tmp2.update()` 或者 `tmp2 |= ...`。
4. **删边的局限性**：
   - 在图中删除一条边后，判断连通性需要重新跑一次完整的搜索。

------

### 正确答案 (离线逆向并查集)

为了高效处理，我们采用**离线处理**：记录所有操作，先删掉所有会断开的边，然后**从后往前**遍历操作。这样“断开边”就变成了“合并边”，可以使用高效的**并查集 (DSU)**。

```python
import sys

# 增加递归深度
sys.setrecursionlimit(200000)

def solve():
    # 使用快读
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n, m, q = map(int, input_data[:3])
    ptr = 3
    
    # 1. 记录初始边
    initial_edges = set()
    for _ in range(m):
        u, v = int(input_data[ptr]), int(input_data[ptr+1])
        if u > v: u, v = v, u
        initial_edges.add((u, v))
        ptr += 2
        
    # 2. 记录询问，并统计哪些边被删除了
    queries = []
    # 使用字典记录被删除的次数，因为同一对朋友可能被多次删除
    del_map = {}
    for _ in range(q):
        op, u, v = map(int, input_data[ptr:ptr+3])
        if u > v: u, v = v, u
        queries.append((op, u, v))
        if op == 1:
            if (u, v) in initial_edges:
                del_map[(u, v)] = del_map.get((u, v), 0) + 1
        ptr += 3
        
    # 3. 并查集（使用字典支持 10^9 的 n）
    parent = {}
    def find(i):
        if i not in parent: parent[i] = i
        if parent[i] == i: return i
        parent[i] = find(parent[i]) # 路径压缩
        return parent[i]

    def union(i, j):
        root_i, root_j = find(i), find(j)
        if root_i != root_j:
            parent[root_i] = root_j

    # 4. 构建最终状态：连接那些从未被删除，或者删除次数已扣完的边
    for u, v in initial_edges:
        if (u, v) not in del_map or del_map[(u, v)] == 0:
            union(u, v)

    # 5. 逆向处理询问
    ans = []
    for i in range(q - 1, -1, -1):
        op, u, v = queries[i]
        if op == 2:
            ans.append("Yes" if find(u) == find(v) else "No")
        else:
            if (u, v) in initial_edges:
                del_map[(u, v)] -= 1
                # 只有当该边所有的删除操作都在逆向中“恢复”了，才执行合并
                if del_map[(u, v)] == 0:
                    union(u, v)
                    
    # 6. 逆向的结果需要翻转
    sys.stdout.write("\n".join(reversed(ans)) + "\n")

if __name__ == "__main__":
    solve()
```

### 核心逻辑图解

这种离线逆向的技巧在处理“删边+连通性”问题时非常高效。你觉得在理解“从后往前处理”这个逻辑上还有困难吗？或者你想尝试分析一下这种方法的复杂度？

## 5. 小美的区间删除

这道题是美团笔试中难度较高的一道，涉及**数论基础（因子分解）**与**双指针（滑动窗口）**的结合。

**题目背景**

小美拿到了一个大小为 $n$ 的数组，她希望删除一个**连续的区间**后，使得剩余所有元素的乘积末尾至少有 $k$ 个 $0$。小美想知道，一共有多少种不同的删除方案？

**限制条件**

- 时间限制：C/C++ 1秒，其他语言 2秒
- 空间限制：C/C++ 256M，其他语言 512M
- $1 \le n, k \le 10^5$
- $1 \le a_i \le 10^9$

**输入描述**

第一行输入两个正整数 $n, k$。

第二行输入 $n$ 个正整数 $a_i$，代表小美拿到的数组。

**输出描述**

输出一个整数，代表删除的方案数。

------

### 示例 1

**输入：**

Plaintext

```
5 2
2 5 3 4 20
```

**输出：**

Plaintext

```
4
```

**例子说明：**

1. 删除 $[3]$ (即数字 3)，剩余 $2, 5, 4, 20$，积为 $800$，末尾有 2 个 0。
2. 删除 $[4]$ (即数字 4)，剩余 $2, 5, 3, 20$，积为 $600$，末尾有 2 个 0。
3. 删除 $[3, 4]$，剩余 $2, 5, 20$，积为 $200$，末尾有 2 个 0。
4. 删除 $[2]$ (即数字 2)，剩余 $5, 3, 4, 20$，积为 $1200$，末尾有 2 个 0。

------

### 2. 思路错误分析

```python
import sys
from functools import cache
def solve(nums, k):
    # 前缀积
    pre = [1] * len(nums)
    pre[0] = nums[0]
    for i in range(1, len(nums)):
        pre[i] = pre[i-1] * nums[i]
    pre = [1] + pre
    # 错误了，要删除的是一个连续的区间
    @cache
    def dfs(left:int, right:int):
        # 表示left,right的闭区间不选择
        if left > right:
            cur = total // (pre[right+1]//pre[left])
            return cur%(10**k)==0                                                                                                                      
        return dfs(left, right-1) + dfs(left+1, right)
    return dfs(0, len(nums)-1)

data = sys.stdin.readline().strip().split()
n, k = int(data[0]), int(data[1])

nums = sys.stdin.readline().strip().split()
nums = [int(x) for x in nums]
total = 1
for x in nums:
    total *= x

ans = solve(nums, k)
print(ans)
```

你的代码主要存在以下三个核心问题：

1. **整数溢出与精度 (致命)**：
   - 你尝试计算 `total` (所有数的乘积) 以及 `total // (pre[right+1]//pre[left])`。
   - 题目中 $a_i \le 10^9$，$n \le 10^5$，乘积会变成一个极其巨大的数字（远超 $2^{64}$），虽然 Python 支持大整数，但在这种量级的计算和除法下，**性能极差且极易超时**。
2. **核心逻辑偏差**：
   - 乘积末尾 $0$ 的个数取决于因子 **2** 和 **5** 的个数。末尾有 $k$ 个 $0 \iff \min(\text{count}(2), \text{count}(5)) \ge k$。
   - 你使用 `cur % (10**k) == 0` 来判断，但这只能判断是否*正好*是 $10^k$ 的倍数，而不能有效统计因子数量（比如 $2^k \times 5^k$ 以外的情况）。
3. **算法复杂度与递归**：
   - 你的 `dfs` 尝试枚举所有区间，但这并不是一个有效的动态规划路径。题目要求的是“删除一个连续区间”，本质上是在寻找一对 `(left, right)`，使得区间外的因子满足条件。
   - 递归和 `@cache` 在处理 $10^5$ 级别的数据时会触发递归深度限制或 OOM。

------

### 3. 正确答案 (双指针/滑动窗口)

**解题思路**：

1. **因子统计**：预处理出数组中每个元素包含因子 $2$ 和 $5$ 的个数。

2. **总量计算**：计算数组中总的因子 $2$ 的个数 `total2` 和因子 $5$ 的个数 `total5`。

3. **滑动窗口**：

   - 我们要删除一个区间 $[L, R]$，使得剩余部分的因子满足：

     `total2 - window2 >= k` 且 `total5 - window5 >= k`。

   - 随着 $R$ 向右移动，窗口内的因子 `window2` 和 `window5` 增加，剩余量减少。

   - 当条件不满足时，我们必须缩小窗口（$L$ 右移）。

   - 对于每一个确定的 $L$，所有满足条件的 $R$ 是连续的。

```python
import sys

def get_factors(n, p):
    count = 0
    while n > 0 and n % p == 0:
        count += 1
        n //= p
    return count

def solve():
    input_data = sys.stdin.read().split()
    if not input_data: return
    n, k = int(input_data[0]), int(input_data[1])
    nums = list(map(int, input_data[2:]))
    
    # 1. 预处理每个数字的 2 和 5 因子数量
    c2 = [get_factors(x, 2) for x in nums]
    c5 = [get_factors(x, 5) for x in nums]
    
    total2 = sum(c2)
    total5 = sum(c5)
    
    # 如果总的因子连 k 个都不够，直接返回 0
    if total2 < k or total5 < k:
        print(0)
        return

    ans = 0
    left = 0
    win2 = 0
    win5 = 0
    
    # 2. 使用双指针（滑动窗口）
    # 我们维护一个窗口 [left, right]，它是我们要“删除”的区间
    for right in range(n):
        win2 += c2[right]
        win5 += c5[right]
        
        # 当删除 [left, right] 导致剩余部分不满足至少 k 个 0 时
        # 我们必须右移左指针，减小被删除的区间，增加剩余的因子
        while left <= right and (total2 - win2 < k or total5 - win5 < k):
            win2 -= c2[left]
            win5 -= c5[left]
            left += 1
            
        # 此时，所有以 right 为右端点，且左端点在 [left, right] 范围内的区间
        # 被删除后都能满足条件。
        # 比如：如果删除 [left, right] 满足，那么删除 [left+1, right] 肯定也满足
        if left <= right:
            ans += (right - left + 1)
            
    print(ans)

if __name__ == "__main__":
    solve()
```

### 关键点解析

- **数论转化**：末尾 $0$ 的数量 $\text{zeros} = \min(\sum \text{factors of 2}, \sum \text{factors of 5})$。
- **复杂度优化**：双指针保证了每个元素最多被访问两次，时间复杂度为 $O(n \log(\max a_i))$，空间复杂度 $O(n)$。
- **计数逻辑**：当固定右端点 `right` 时，如果区间 `[left, right]` 被删除后满足条件，那么比它短的区间 `[left+1, right], ..., [right, right]` 被删除后一定也满足（因为剩下的因子更多了）。所以贡献是 `right - left + 1`。
